iOS and Android libraries in Tern

Write the logic once, compile it for both phones, and call it from Swift and Kotlin. Same language, same race checks, no changes per platform.

curl -fsSL https://ternlang.dev/install.sh | sh
tern new myapp && cd myapp

Same code, every target

fn main():
    squares = [0] * 8
    parallel for i in 0..len(squares):
        squares[i] = i * i
    print(squares)
tern run --target ios-sim squares.tn        # boots a Simulator if none is running
tern run --target android squares.tn        # pushes with adb, runs, cleans up
tern build --lib --target ios lib.tn        # a static library + C header for Xcode

Questions

Can I use Tern in an iOS app?

Yes. Build with --lib --target ios to get a static library and a C header, link it into your Xcode project, and call the exported functions from Swift.

Can I use Tern in an Android app?

Yes. Build for android or android-x86_64 with the NDK and call it from Kotlin or Java through JNI.
