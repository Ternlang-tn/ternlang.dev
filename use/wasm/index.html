WebAssembly with Tern

Add --target wasm to run a program under wasmtime or Node, or --lib to get a module JavaScript can import, with TypeScript types.

curl -fsSL https://ternlang.dev/install.sh | sh
tern new myapp && cd myapp

A library for JavaScript

lib.tn
export fn word_count(text: str) int:
    n = 0
    for w in text.split(" "):
        if w.trim() != "":
            n += 1
    return n
tern build --lib --target wasm lib.tn     # lib.wasm (41 KB), lib.mjs, lib.d.ts
app.mjs
import { load } from "./lib.mjs";
const lib = await load();
console.log(lib.word_count("to be or not to be"));   // 6n

The loader works in Node and the browser, and runtime errors arrive as a JavaScript TernError. The WebAssembly guide covers how values cross over.

In production

ternTS, our TypeScript transpiler, is Tern compiled to a 2 MB wasm module. You can run it on a whole project in your browser.

Questions

Can Tern compile to WebAssembly?

Yes. --target wasm builds a WASI program; --lib --target wasm builds a module with a JavaScript loader and TypeScript types; --target wasm-threads adds threads.

What doesn't work on wasm?

sqlite and http.serve, and with plain --target wasm, parallel code runs one task after another.
