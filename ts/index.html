Correct

  
tsc’s output, checked three ways.

  

    

      
1. The same program as tsc. Every file goes through ternTS and through TypeScript 5.9’s transpileModule with the same options, and both outputs are parsed and compared, ignoring only formatting and the numbering of temp names like _a. That’s the check the playground above runs.

      
2. Nest’s own test suite. All 3,631 of Nest’s unit tests pass with ternTS as the TypeScript transformer.

      
3. Real apps, same behavior. Nine NestJS sample apps built with tsc and with ternTS answer the same requests byte for byte, including the Swagger document and GraphQL schema that Nest builds from decorator metadata.

Experimental

  
Install

  
An early, experimental release: expect rough edges, and please tell us what breaks. The npm package carries a native binary for macOS and Linux (arm64 and x64) and WebAssembly for everything else, so you never install Tern.

  
npm i -D @ternlang/ternts@experimental
npx ternts build                # the project in ./tsconfig.json: files, outDir, module, decorators, jsx…
npx ternts dev --warm           # build, run, and restart on every save (replaces nest start --watch)

  

    
Jest
// jest.config.js
transform: {
  '^.+\\.(t|j|mj)sx?$': ['@ternlang/ternts/jest', { tsconfig: 'tsconfig.json' }],
}

    
Vite and Vitest
// vite.config.ts
import ternts from '@ternlang/ternts/vite';
export default defineConfig({ plugins: [ternts()] });

    
Node
# run TypeScript directly (Node 22.15+)
node --import @ternlang/ternts/register src/main.ts

  

  
Not done yet

  
    
    
  • Type checking, by design: keep tsc --noEmit (or tsgo) for that, as swc users do.
    • 
    
  • Targets below ES2022. Output uses class fields and static blocks: Node 16.11+ and current browsers.
    • 
    
  • TC39 standard decorators. Only the legacy kind (experimentalDecorators), which NestJS, TypeORM and Angular use.
    • 
    
  • Windows has the WebAssembly build for Jest, Vite and Node, but not ternts build yet.
    • 
  






  

    
Written in Tern

    
About 10,000 lines of Tern.

    
ternTS is written in Tern, a compiled language built for AI agents to write, that compiles to native code faster than Rust and Go. There’s no AST: the parser walks tokens and copies your source through, editing only what TypeScript adds.
