Comparison

Tern vs Go

Both compile to one binary and keep the language small. Tern reads like Python, has no nil and no data races, and is faster on our benchmarks. Go is mature and has a huge ecosystem.

curl -fsSL https://ternlang.dev/install.sh | sh
tern new myapp && cd myapp

What’s different

  • No nil, no exceptions. Option[T] and Result[T, E] with ? instead of if err != nil.
  • Values, not pointers. Every value is a copy (lazily), so there’s no aliasing, and the compiler rejects data races in parallel code. Go finds races only at run time with -race.
  • Goroutines become parallel blocks and tasks, on a work-stealing scheduler.
  • Generics and enums with data, matched with match.

Pick Go when

  • You need a mature ecosystem, Windows, or a language your team already knows.
  • You need stability guarantees today. Tern is an early release.

Questions

Is Tern faster than Go?

On our benchmarks, yes: ahead on all 10 compute benchmarks and on HTTP throughput per thread. Go served slightly more redirects per second in the agent-built app test.

Is Tern like Go?

In spirit: one binary, a small language, fast builds. The syntax is Python-like, and there is no nil and no shared mutable data.
